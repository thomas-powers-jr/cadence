# 321-01 — pin brace-expansion and except braces advisory

## Objective

Make the required `security-success` check green again. Since three high-severity denial-of-service advisories were published, `scripts/check-audit-exceptions.mjs` fails every PR and `main` itself: `GHSA-vfj7-8cjw-p6xm` (`braces`, published 2026-09-18) and `GHSA-qhr7-859c-m2p7` / `GHSA-6j4f-fj2g-mc7p` (`brace-expansion`, published 2026-09-29). PR #546 (phase 320) is the first PR blocked by it; main's last green Security run was 2026-09-28. All three are dev-only. `pnpm why braces -r --prod` and `pnpm why brace-expansion -r --prod` are both empty. `brace-expansion@5.0.9` arrives via the eslint / typescript-eslint toolchain (`minimatch@10.2.6`), and `braces@3.0.3` via `@changesets/cli@2.31.1` → `@manypkg/get-packages` → `globby@11` → `fast-glob` → `micromatch@4.0.8`. The two cases are handled differently:
- `brace-expansion` has a fix (`>=5.0.11`). The stale `"brace-expansion@5.0.6": "^5.0.9"` override, whose key matches nothing that resolves today, becomes the range key `"brace-expansion@^5.0.0": "^5.0.11"`, which cannot rot the same way.
- `braces` has **no patched release** (`<= 3.0.3`, `first_patched_version: null`). The operator approved, on 2026-10-04, a time-boxed exception row with a firm expiry and a named unblock condition: a patched `braces`, or adopting `@changesets/cli` 3.x (Dependabot #474 drops `braces` from the tree). It is deliberately not a release-tooling major bump right before a release.

**As built (2026-10-04):** the whole-branch review corrected the timeline above. PR #546 was not the first PR blocked, and `main` itself was never observed failing (no `main` Security run exists after the green 2026-09-28 run). Dependabot PR #545 (2026-10-02, a workflow-only diff, so `main`'s tree) failed first, on the two `brace-expansion` advisories only. `braces` first appeared in PR #546's run (2026-10-04). Also, `GHSA-6j4f-fj2g-mc7p` is fixed in `5.0.10`; only `GHSA-qhr7-859c-m2p7` needs `5.0.11`. The changeset and ROADMAP entry state the corrected facts.
