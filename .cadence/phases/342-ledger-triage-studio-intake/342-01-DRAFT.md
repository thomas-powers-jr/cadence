# 342-01 — Retire the needs-decision backlog and intake Studio's upstream asks

## Objective

Bring the Praxis ledger back in line with reality in one decisions-only pass. First, file Cadence Studio's nine upstream asks (cadence-studio `docs/roadmap/2026-10-26-poc-roadmap.md` §3) and Studio's `rec-20261028-008` here, deduplicated against existing recs, so the loop can see them. Ship no product code; the ledger and the test that pins it are the deliverable (precedent: phase W of the v1.57 arc, and phase 284).
